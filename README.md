## 💫 About Me

🎓 **Aspiring DevOps Engineer | BCA (IBM Program) @ Maharishi University | Linux | Git | Docker | CI/CD** 🚀

I'm a BCA student based in **Lucknow, India**, building a strong foundation in DevOps through consistent, hands-on learning. I'm genuinely curious about how software moves from a developer's machine to production — how it's version-controlled, packaged, deployed, and kept running reliably.
